# Dragon Ball Soul Legacy

Protótipo de RPG de ação 2D feito em Godot 4, inspirado na estrutura de gameplay de jogos como *Legacy of Goku* e *Buu's Fury*.

## Objetivos iniciais

- movimento em 8 direções;
- combate corpo a corpo e Ki;
- progressão de RPG;
- mapas 2D em pixel art;
- arquitetura preparada para multiplayer cooperativo no futuro.

## Tecnologia

- Godot 4.7;
- GDScript;
- renderizador GL Compatibility;
- Git/GitHub para versionamento.

## Estado atual

Fundação do projeto e organização da arquitetura.
